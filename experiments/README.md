# experiments

Skills under trial. Not part of the bundle and not discovered by pi: load one
on demand by asking the model to read its `SKILL.md` by path, e.g.
`~/.pi/harness/experiments/methodology/SKILL.md`.

- `architecture-postulates/` — the postulates, written directly as a skill
- `methodology/` — `methodology.yaml` is the source; `bun experiments/methodology/build.ts` regenerates `SKILL.md` (committed)
